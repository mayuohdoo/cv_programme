    📦 安装步骤

    1
    下载插件文件

    从 GitHub 仓库 下载 chrome-extension-mvp 文件夹

    2
    打开 Chrome 扩展页面

    地址栏输入 chrome://extensions，开启右上角「开发者模式」

    3
    加载插件

    点击「加载已解压的扩展程序」→ 选择 chrome-extension-mvp 文件夹

    4
    开始使用

    点击浏览器右上角插件图标 → 上传简历 → 解析 → 去招聘网站自动填充
