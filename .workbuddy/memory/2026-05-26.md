## Onboarding 头像选择 → 3D 图片头像替换（第二版，当前版本）

**任务**：将 emoji 头像替换为 `assets/avatars/` 下的 3D cartoon avatar PNG 图片。

**修改文件**：
1. `index.html`（CSS：`.ob-avatar-option` 适配 img、`.ob-avatar-img` 预览样式）
2. `onboarding.js`（4 处修改：预览 HTML 结构、头像网格 12 选项、点击事件处理、updateSidebar 兼容）

**关键变更**：
- `ob-avatar-preview`：从 `<span class="ob-avatar-emoji">` 改为 `<img class="ob-avatar-img">`
- 头像网格：12 个 emoji option 全部替换为 `<img src="assets/avatars/avatar-XX.png">`
- `data-avatar`：保存图片路径如 `assets/avatars/avatar-01.png`
- `updateSidebar`：图片路径检测 → `a.innerHTML` 渲染 `<img>`；emoji 回退 → `a.textContent`
- 点击预览同步：检测 `/\\.(png|jpg|jpeg|gif|webp|svg)/i` 决定图片/文字模式
- CSS：`object-fit: contain`、`border-radius: 24px` 卡片、`padding: 4px` 防裁切
- 每张图片带 `onerror` 保护：加载失败时隐藏该卡片

**旧用户兼容**：
- localStorage key `userProfile` 不变
- emoji 用户：`updateSidebar` 和预览区均支持 emoji textContent 回退
- 图片用户：img 直接设置 src
- 用户需准备 `assets/avatars/avatar-01.png` 至 `avatar-12.png` 透明背景 PNG
